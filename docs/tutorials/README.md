3. [Models and Relationships](building-a-blog/03-models-and-relationships.md) - Define Active Record models with associations
4. [CRUD Operations](building-a-blog/04-crud-operations.md) - Implement create, read, update, and delete functionality
5. [Adding Features](building-a-blog/05-adding-features.md) - Extend your blog with comments, tags, and more

# Tutorials

Step-by-step lessons that build a working project with CQL. Each step shows the code to write and the output to expect.

## Getting Started

- [Your First CQL App](getting-started/your-first-cql-app.md): connect to SQLite, migrate, model, query and validate
- [Adding CQL to an Existing Project](getting-started/adding-cql-to-existing-project.md): map existing tables and adopt CQL one query at a time

## Building a Blog

One project across five parts; each part adds to the previous one.

1. [Project Setup](building-a-blog/01-project-setup.md): create the project and connect to the database
2. [Database Schema](building-a-blog/02-database-schema.md): write and run the migrations
3. [Models and Relationships](building-a-blog/03-models-and-relationships.md): map the tables and their associations
4. [CRUD Operations](building-a-blog/04-crud-operations.md): create, query, update and delete records
5. [Adding Features](building-a-blog/05-adding-features.md): validations, callbacks, transactions, seeding and statistics

## Real-World Examples

- [Performance Monitoring](real-world-examples/performance-monitoring.md): log queries, find N+1 queries and report on performance

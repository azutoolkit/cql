# Use UUID and ULID Primary Keys

Key a model on a UUID or a ULID that CQL generates in your application before the `INSERT`.

| Model type parameter | `id` type | Generated by | Stored as |
| --- | --- | --- | --- |
| `Model(Int32)` / `Model(Int64)` | `Int32?` / `Int64?` | the database (auto-increment) | integer |
| `Model(UUID)` | `UUID?` | `UUID.random` | text, 36 characters |
| `Model(String)` | `String?` | `CQL::ULIDCompat.generate` | text, 26 characters |

The key is stored as text, so this works the same on SQLite, PostgreSQL, MySQL and CockroachDB.

## UUID Keys

```crystal
AppDB = CQL::Schema.define(:app_db, adapter: CQL::Adapter::SQLite, uri: "sqlite3://./app.db") do
  table :sessions do
    primary :id, String, auto_increment: false # UUID stored as text
    text :token
    bigint :user_id
    timestamps
  end
end

class Session
  include CQL::ActiveRecord::Model(UUID)     # no id property: the module adds a UUID id

  property token : String = ""
  property user_id : Int64 = 0_i64
  property created_at : Time?
  property updated_at : Time?

  def initialize
  end

  def initialize(@token : String, @user_id : Int64)
  end
end

session = Session.create!(token: "abc", user_id: 1_i64) # any :id you pass is dropped
session.id      # => UUID?
session.id!     # => UUID, raises if the record has no id yet; id= takes a UUID

Session.find!(session.id!)
Session.query.where { id == session.id! }.all            # binds the UUID as text
Session.query.where_primary_key([session.id!, UUID.random]).all # id.in([...]) does not compile on a UUID key yet
Session.find_or_create_by(token: "abc")
```

`CQL_VALIDATE_SCHEMA_MAPPINGS=1` accepts a `UUID` getter against a `String` column (see [Dump and Validate Your Schema](../migrations/schema-dump-and-validation.md)).

## ULID Keys

A ULID sorts by creation time, so new rows sort after old ones. Use `Model(String)`:

```crystal
table :events do      # in AppDB
  primary :id, String, auto_increment: false # ULID stored as text
  text :event_type
  timestamps
end

class Event
  include CQL::ActiveRecord::Model(String)

  property event_type : String = ""
  property created_at : Time?
  property updated_at : Time?
end

event = Event.create!(event_type: "user.created")
event.id!       # => "01JB9Y6ZK3M8X2Q4R7T5V1W0NC"
```

`CQL::ULIDCompat.generate` writes 10 Crockford base32 characters of millisecond timestamp, then 16 random ones:

- Ids from different milliseconds sort by creation time; ids from the same millisecond are in random order.
- It is not a cryptographic generator, so never use a ULID as a secret token.
- Every `Model(String)` generates a ULID on `create!`. To supply your own string keys (slugs, external ids), store them in another column.

{% hint style="info" %}
The id is generated before the `INSERT`, so a rolled-back transaction simply discards it. With 128-bit ids this is harmless.
{% endhint %}

## Associations on a UUID Key

```crystal
class SessionNote
  include CQL::ActiveRecord::Model(Int64)

  @[DB::Field(converter: CQL::UUIDConverter)]  # reads the text column; rejects NULL
  property session_id : UUID
end

class Session
  has_many :notes, SessionNote, foreign_key: :session_id, dependent: :destroy
end

# Models cannot write a UUID column other than their key yet, so
# SessionNote.create!(session_id: ...) and session.notes.create(...) do not compile
AppDB.insert.into(:session_notes).values(session_id: session.id!.to_s).commit

session.notes.count   # => 1
session.delete!       # destroys the notes, then the session
```

A `has_many` or `has_one` owned by a UUID-keyed model binds the owner's id as text, so its queries and its [`dependent:` strategies](../relationships/has-many.md#when-the-parent-is-deleted) work as with integer keys. So do a `many_to_many`'s queries, its join-row cleanup on delete, and `dependent: :destroy`. Its `:delete_all`, `ids`, `ids=` and `delete(id)` need the owner and the targets to share a key type.

## Convert Plain Structs

Models convert for you. A `DB::Serializable` struct that is not a model uses the converters directly:

```crystal
struct Token
  include DB::Serializable

  @[DB::Field(converter: CQL::UUIDConverter)]   # from_rs: text -> UUID; to_db: UUID or nil -> text
  property id : UUID
  property label : String
end

struct Preference
  include DB::Serializable

  property id : Int64
  @[DB::Field(converter: CQL::JSONBConverter)]  # PostgreSQL json/jsonb -> JSON::Any; to_db: to_json
  property settings : JSON::Any
end
```

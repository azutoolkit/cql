# CQL Documentation

Welcome to **CQL (Crystal Query Language)** - the most comprehensive, type-safe ORM for Crystal!

CQL combines the power of raw SQL with Crystal's compile-time type safety, offering an intuitive Active Record pattern while maintaining flexibility for Repository and Data Mapper patterns.
